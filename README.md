# Multimedia Techniques Playground

This repository is my personal playground for multimedia topics. I use it to push tests, experiments, and any ideas I want to explore about multimedia.

## Course Introduction

Multimedia data is being created at an increasingly large scale from many different sources. This creates valuable opportunities to build intelligent solutions and services for real-life needs.

In this course, learners are equipped with both foundational and advanced knowledge in multimedia data analysis and processing. Learners can apply these concepts and techniques to practical applications, and also pursue deeper research directions, such as:

- Processing and analyzing multimedia data
- Extracting traditional and deep-learning-based features from multimedia data for different real-world tasks
- Combining multiple data types/sources in intelligent systems

The course also aims to encourage deeper research in other graduate-level subjects related to processing different multimedia data types and sources.

## Course Contents

- Overview of multimedia and multimedia systems
- Multimedia data representation
- Spatial-domain and frequency-domain filtering
- Feature extraction for common multimedia data types
- Applications of machine learning and deep learning in multimedia analysis and processing
- Problems and applications on visual data
- Problems and applications on other data types
- Problems and applications involving multimodal data fusion
